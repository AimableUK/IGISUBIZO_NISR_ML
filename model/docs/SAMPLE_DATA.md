# Sample Data

## What it is

Deterministically generated district-level labour market data that mirrors the structure of real NISR LFS and Establishment Census aggregates. Used so the full product can be built and tested end-to-end before real microdata is available.

All outputs are labelled `isSample: true` everywhere - in the API response, the UI, and every artifact saved to the database.

Most Python model analyses also read generated proxy CSVs from `model/data/real/`. Despite that directory name, these are not verified extracts of official NISR tables. They are marked as sample/demo data in results and must not be used as official statistics. The general query engine additionally reads the public NISR crop-yield table under `model/data/official/`; see its `source.json` for provenance. Its reference year is not provided.

## Files (Python CSVs - reference only)

These CSVs in `model/data/sample/` were generated by `model/generate_sample.py` and document the expected column structure for real data:

| File | Rows | Description |
|---|---|---|
| `district_labour.csv` | 210 (30 districts × 7 years) | LFS-structure district aggregates |
| `district_establishments.csv` | 210 | Establishment Census district aggregates |
| `sector_employment.csv` | 1890 (30 × 7 × 9 sectors) | Sector employment share per district per year |

## Legacy TypeScript sample engine

The unused alternative (`api/src/services/ml-engine.ts`) generates deterministic sample data in-process via `buildDistrict()` and `buildSector()`. The active analysis route calls the Python FastAPI service.

## Column reference - district_labour

| Column | Kind | Description |
|---|---|---|
| `district` | geo | District name |
| `province` | category | Province |
| `year` | time | Survey year |
| `employment_rate` | percent | % of working-age population employed |
| `unemployment_rate` | percent | % of labour force unemployed |
| `underemployment_rate` | percent | % of employed working below capacity |
| `youth_neet_rate` | percent | % of youth not in employment, education or training |
| `labour_force_participation` | percent | LFP rate |
| `pct_agriculture` | percent | Share in agriculture |
| `pct_industry` | percent | Share in industry |
| `pct_services` | percent | Share in services |
| `pct_formal` | percent | Share in formal employment |
| `median_hours_worked` | number | Median weekly hours |
| `avg_wage_rwf` | number | Average wage (RWF) |
| `pct_secondary_plus` | percent | Share with secondary or higher education |
| `pct_tvet` | percent | Share with TVET qualification |
| `population_15_64` | number | Working-age population |

## Plugging in real data

1. Download NISR LFS microdata from https://microdatabk.statistics.gov.rw/catalog/125
2. Aggregate to district × year summary tables matching the column names above
3. Replace the generated CSVs in `model/data/real/` with validated aggregated tables
4. Update the Python engine metadata and mark only the verified dataset as official; do not change the core loader's `IS_SAMPLE_DATA` flag for unrelated proxy datasets
5. Update dataset versions and source citations to match the actual data
